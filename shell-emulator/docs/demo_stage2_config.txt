$ python3 main.py --help
usage: emulator [-h] [--vfs PATH] [--script PATH] [--headless]

Эмулятор оболочки UNIX-подобной ОС (GUI) с виртуальной ФС из ZIP-архива.

options:
  -h, --help     show this help message and exit
  --vfs PATH     путь к ZIP-архиву с VFS (по умолчанию — пустая ФС)
  --script PATH  путь к стартовому скрипту с командами эмулятора
  --headless     консольный режим без окна (для автоматических тестов)
[код возврата: 0]
